# Zedbury Game Kit

Small, deep, reliable libraries for web games. Each package works on its own, has no dependencies, and runs in every browser, Node, Bun and Deno.

| Package | What it does | Status |
|---|---|---|
| [`luckbox`](packages/luckbox) | Randomness for games that you can replay: seeds, dice, loot tables, gacha odds, shuffle bags, daily challenges | In progress |
| `saveslot` | Crash-safe save slots with version upgrades | Planned |

## Working on the kit

```bash
npm install
npm run check   # types, build, tests, size and package checks for every package
```
